# Collection of Prompts

This folder groups the core execution-trigger prompts used to run automated workflows.

---

- **[Start Collecting All](start-collecting-all.md)** — runs News, Field Monitor, Email, and Daily Intelligence Brief collection in parallel.
- **[Clean All](clean-all.md)** — applies retention rules across all report sections, archiving excess pages.
- **[Daily Intelligence Brief — Sub-Agent Prompt](daily-intelligence-brief-sub-agent-prompt.md)** — the underlying prompt used by the Daily Intelligence Brief sub-agent.
- **[Email Whitelist Monitor — Prompt](email-whitelist-monitor-prompt.md)** — monitors whitelisted senders for priority email handling.
- **[Aggregated Report (TTS)](aggregated-report-tts.md)** — merges today's Daily Brief reports into a clean, TTS-ready summary.
- **[Collecting - Newsletter Digest (Expand)](collecting-newsletter-digest-expand.md)** — expands newsletter emails into clean readable docs.
- **[Collecting - AI/Robotics Investment Signals](collecting-ai-robotics-investment-signals.md)** — 3-agent pipeline: News Collector → Analyzer → Signal Generator.
